# إصلاح تشغيل Local AI — ابدأ من هنا

## الملف الوحيد الذي تشغّله أولًا

1. نزّل `LocalAI-Full-Installer-PAUSEFIX.zip`.
2. اضغط بزر الفأرة الأيمن على الملف واختر **Extract All / استخراج الكل**. لا تشغّل أي ملف من داخل نافذة ZIP.
3. افتح المجلد المستخرج.
4. شغّل **`INSTALL-ALL.bat`** بالنقر المزدوج. لا تشغّل ملفات `.ps1` بالنقر المزدوج.
5. ستبقى نافذة التثبيت مفتوحة عند النجاح أو الفشل وتنتظر ضغط أي مفتاح. اقرأ أول رسالة `FAILED` أو `ERROR`.

## قبل التثبيت

- جهازك المستهدف: Windows 11 64-bit، i7-1185G7، RAM 16GB، Intel Iris Xe.
- يحتاج إلى اتصال إنترنت وWinGet (App Installer).
- يستخدم القرص `D:\LocalAI` ويحتاج مساحة فارغة كافية؛ المثبت يفحص المساحة قبل تنزيل النماذج.
- لا تستخدم Run as administrator إلا إذا طلب Windows ذلك.

## إذا فشل المثبت

1. لا تغلق النافذة قبل قراءة رسالة الخطأ.
2. من المجلد المستخرج شغّل `DIAGNOSE.bat`. سيُنشئ تقريرًا على سطح المكتب.
3. ارفع التقرير هنا. لا يحتوي التقرير على مفاتيح API أو محتوى ملفات الأسرار؛ راجعه مع ذلك قبل الإرسال لإزالة أي مسارات شخصية لا تريد مشاركتها.
4. سجلات التثبيت عند توفرها توجد في `D:\LocalAI\Logs`، كما يوجد سجل للمثبت الكامل في `%TEMP%`.

## أوامر أخرى

- `VERIFY-INTEGRITY.bat`: يتحقق من سلامة ملفات الحزمة ولا يثبت شيئًا.
- `D:\LocalAI\Platform\START-CHAT.bat`: تشغيل منصة المحادثة بعد التثبيت. اترك نافذته مفتوحة أثناء الاستخدام.
- `D:\LocalAI\Platform\IMPORT-FILTERS.bat`: استيراد الفلاتر بعد إنشاء حساب المسؤول في Open WebUI.

## ما الذي تغير؟

- كل ملفات BAT تنتظر ضغط مفتاح حتى لا تختفي رسائل الخطأ.
- المثبت الكامل يكتب سجل تنسيق مستقلًا في `%TEMP%` (من دون بدء Transcript متداخل)، ومثبتا المحرك والمنصة ينشئ كل منهما Transcript خاصًا به؛ كما ينظف ملفات حالة النجاح القديمة أولًا حتى لا يعطي نجاحًا وهميًا.
- أضيف `DIAGNOSE.bat` لتجميع معلومات تشخيص غير سرية.
- أُبقيت سكربتات المحرك والمنصة والفلاتر كما هي وظيفيًا؛ التغيير الأساسي هنا لإظهار الفشل بدل إخفائه وتسهيل التشخيص.

**تنبيه:** اختبارات Python والفلاتر وسلامة ZIP أجريت في بيئة الإنشاء. لا يمكن إجراء اختبار WinGet أو Ollama أو Open WebUI على Windows الحقيقي الخاص بك من هنا؛ لذلك التثبيت النهائي لا يُعد مؤكدًا قبل ظهور `STATUS: SUCCESS` على جهازك.
