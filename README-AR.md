# LocalAI Studio — الإصدار 2.6

## التشغيل

1. تأكد أن تطبيق Ollama يعمل.
2. فك ضغط هذه الحزمة بالكامل.
3. اضغط مرتين على LocalAI-Studio.bat.

هذا كل ما تحتاجه للتشغيل اليومي. الملف نفسه يتحقق من سلامة الحزمة، ويكمل التثبيت أو الإصلاح عند الحاجة، ثم يشغّل المحادثة ويفتح المتصفح. بعد أول إعداد، استخدم الزر نفسه في كل مرة.

المحادثة: http://127.0.0.1:8080

## لماذا هذه النسخة أصغر؟

تم دمج أوامر التشغيل في ملف BAT واحد. أزيلت أغلفة BAT المتكررة، ولوحة Dashboard ثانية منفصلة عن Open WebUI، واختبارها، وخيار تنزيل نموذج 4B الاختياري، وملفات الدليل/الإصدار المكررة. لا تحتاج هذه الملفات لتشغيل Qwen 3.5 9B الموجود عندك.

الحزمة الآن 17 ملفًا فقط، وملف BAT واحد.

في الإصدار 2.6 أُزيلت استدعاءات CALL الفرعية من ملف BAT بالكامل؛ كل أمر يشغّل ملف PowerShell مباشرة. كما أصبح فحص الحزمة يختبر تسميات BAT والملفات التي يستدعيها، وليس البصمات فقط.

## ما الذي يحافظ عليه المشروع؟

- لا يثبت Ollama من جديد، ولا يوقفه أو يغير إعداداته.
- لا ينزل Qwen 3.5 9B مرة أخرى ولا يحذف أو ينقل ملفات النموذج.
- يعيد استخدام البيئة الموجودة في D:\LocalAI\Platform\.venv وبيانات Open WebUI وقاعدة المحادثات.
- لا يحذف D:\LocalAI\Platform\Data أو مفاتيح التوقيع أو المحادثات.
- الإصلاح لا يبدأ مثبتًا ثانيًا إذا كان تثبيت سابق لا يزال يعمل.

## إصلاح Windows الذي عالج تعطل Open WebUI

كان Open WebUI 0.13.5 يستدعي tempfile.mkdtemp(..., dir='/tmp') داخل utils/machines/managed.py. المسار /tmp غير موجود افتراضيًا في Windows، لذلك كان الخادم ينهار أثناء استيراد وحدات التطبيق.

المشغّل الآن:
- ينشئ D:\LocalAI\Platform\Data\Temp ويضبط متغيرات TEMP وTMP وTMPDIR.
- يتحقق أن نسخة Open WebUI هي 0.13.5 قبل تطبيق التغيير.
- يحفظ نسخة أصلية من managed.py في D:\LocalAI\Platform\Backups\OpenWebUI\managed.py.original.
- يغير السطر المحدد فقط ليستخدم مجلد Python المؤقت الخاص بويندوز.
- يتحقق أن المجلد قابل للكتابة، ولا يعيد تطبيق التعديل إذا كان موجودًا.

لا تُعدّل الحزمة ملفات JavaScript المبنية أو قاعدة بيانات المحادثات.

## النموذج والموارد

النموذج الأساسي: local-qwen35:latest — Qwen 3.5 9B، وهو النموذج المثبت بالفعل في Ollama بحسب سجلات التثبيت السابقة. يختاره المشغّل تلقائيًا بعد التأكد من وجوده.

- يرسل اختبار النموذج طلبًا حقيقيًا إلى Ollama ولا ينزل أي نموذج.
- يبدأ سياق التشغيل عند 4096 لتقليل ضغط الذاكرة.
- لا يعلن التطبيق أن كل نموذج يدعم الصور أو البحث؛ تُستخدم قدرات النموذج الفعلية.
- Whisper Small عبر faster-whisper هو مسار تحويل الصوت إلى نص. يحتاج FFmpeg لمعالجة بعض التسجيلات.
- لا تتضمن الحزمة نموذج TTS عربيًا مثبتًا ومتحققًا منه، ولا مولد صور أو فيديو. Qwen 9B نموذج محادثة وفهم، وليس مولد صور أو فيديو.

على جهاز CPU رباعي النواة ورسوميات مدمجة، قد يكون الاستدلال بطيئًا. تجنب تشغيل Whisper والنموذج الكبير معًا عندما تكون الذاكرة ممتلئة.

## الأوامر الإضافية

كلها من الملف نفسه، ولا توجد ملفات BAT أخرى:

| الأمر | وظيفته |
|---|---|
| LocalAI-Studio.bat repair | تثبيت أو إصلاح منصة المحادثة فقط |
| LocalAI-Studio.bat stop | إيقاف Open WebUI الذي بدأه المشغّل؛ لا يوقف Ollama |
| LocalAI-Studio.bat check | فحص Ollama والنموذج وOpen WebUI والصوت وإصلاح Windows |
| LocalAI-Studio.bat test | اختبار استجابة فعلية من Qwen |
| LocalAI-Studio.bat filters | استيراد الفلاتر الثلاثة الاختيارية |
| LocalAI-Studio.bat restore-style | استرجاع ملف CSS الأصلي إذا أردت التراجع عن الثيم |
| LocalAI-Studio.bat verify | فحص البصمات ومسارات المشغّل وملفاته المطلوبة |
| LocalAI-Studio.bat help | عرض هذه الأوامر |

بعد أول تشغيل، أنشئ حساب المسؤول الأول في Open WebUI.

### الفلاتر الاختيارية

تحتوي الحزمة على ثلاثة فلاتر:
1. Trusted Content Guard: يعامل الملفات والاقتباسات والويب ومخرجات الأدوات كبيانات غير موثوقة، لا كتعليمات تتحكم بالمساعد.
2. Accuracy & Thinking: يضيف إرشادات الدقة ويطلب قيمة التفكير المنطقية لنموذج Qwen المستهدف.
3. Selective Self Review: يراجع بعض الحسابات والأكواد والردود التي تحتاج تدقيقًا باستدعاء ثانٍ للنموذج نفسه. ليس تحققًا مستقلاً ولا يضمن الصحة.

للاستيراد، أنشئ Admin API Key من Settings → Account، ثم نفّذ الأمر filters. سيُطلب المفتاح في إدخال مخفي، ولن يُكتب في ملفات المشروع. الفلاتر تنفذ Python داخل خادم Open WebUI، لذلك لا تستورد إلا ملفات راجعتها.

### واجهة الموقع

يحمل Open WebUI اسم LocalAI Studio ويستخدم ملف CSS محليًا لتحسين الخطوط والتركيز والتنقل بلوحة المفاتيح وتقليل الحركة. يحتفظ المشغّل بالملف الأصلي قبل التعديل. يمكن التراجع بالأمر restore-style.

## الخصوصية والسجلات

- يستمع Open WebUI على 127.0.0.1:8080 محليًا، وليس على الشبكة.
- البحث عبر DuckDuckGo يرسل نص الاستعلام إلى مزود البحث الخارجي؛ لا تضع كلمات مرور أو معلومات خاصة في الاستعلام.
- سجلات تشغيل Open WebUI: D:\LocalAI\Platform\Logs
- سجلات التثبيت: D:\LocalAI\Logs
- حالة المنصة: D:\LocalAI\Platform\PLATFORM-STATUS.txt

لا تحذف D:\LocalAI\Models أو D:\LocalAI\Platform\Data أو مجلد النسخ الاحتياطية بغرض إصلاح خطأ تشغيل.
