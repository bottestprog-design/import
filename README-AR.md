# استكمال Local AI — بدون إعادة تنزيل النموذج

## ما كشفه تقرير جهازك

- Ollama 0.40.18 يعمل على `127.0.0.1:11434`.
- النموذج موجود بالفعل بالاسمين `local-qwen35:latest` و`qwen3.5:9b-q4_K_M`.
- كل طبقات النموذج مكتملة في `D:\LocalAI\Models`، ولا توجد أجزاء تنزيل ناقصة.
- لذلك هذه الحزمة **لا تثبّت Ollama ولا تعيد تنزيل Qwen ولا تلمس مجلد Models**.
- المنصة لم تكن موجودة: لا مجلد Platform ولا Python venv ولا Open WebUI ولا Filters ولا FFmpeg.

## لماذا فشل المثبت السابق؟

المثبت القديم كان يشترط وجود `D:\LocalAI\ENGINE-STATUS.txt` قبل تثبيت المنصة. هذا الشرط غير صحيح: النموذج موجود ويعمل في Ollama حتى لو لم ينشئ المثبت القديم ملف الحالة. هذا المثبت يتحقق من `/api/version` و`/api/tags` مباشرة ولا يعتمد على ملف حالة وهمي.

## تثبيت المنصة فقط

1. فك ضغط ZIP بالكامل في مجلد جديد.
2. شغّل `VERIFY-PACKAGE.bat` للتأكد من بصمات كل الملفات، ثم شغّل `INSTALL-PLATFORM.bat`.
3. المثبت يستخدم Python 3.11 الموجود في تقرير جهازك (أو 3.12 إن كان المتاح فقط). Open WebUI يدعم pip على Python 3.11 و3.12.
4. أثناء التثبيت يطلب المثبت مؤقتًا منع سكون النظام فقط (ES_SYSTEM_REQUIRED)، ولا يمنع إطفاء الشاشة. يعيد الحالة الطبيعية عند انتهاء المثبت أو فشله؛ لا يغيّر إعدادات Sleep الدائمة.
5. يثبت Open WebUI 0.13.5 داخل `D:\LocalAI\Platform\.venv`، ويثبت PyAV 14.0.1 وfaster-whisper داخل البيئة نفسها.
6. يحاول تثبيت FFmpeg عبر WinGet. إذا فشل تنزيل FFmpeg، يظل الشات النصي متاحًا وتظهر حالة تحذير خاصة بالصوت.
7. يحاول تنزيل Whisper Small متعدد اللغات وتشغيل تحميل تجريبي CPU INT8. إذا تعذر الوصول إلى Hugging Face، فلن يتعطل تثبيت الشات؛ يظهر التحذير في `PLATFORM-STATUS.txt`.
8. ينسخ الفلاتر إلى `D:\LocalAI\Platform\Filters` ويختبرها قبل اعتماد التثبيت.
9. ينشئ ملفات حالة فعلية للمحرك والمنصة والمشروع حتى لا تعتمد أدوات الفحص على حالة تثبيت قديمة أو غير صحيحة.

## التشغيل

- شغّل `D:\LocalAI\Platform\START-CHAT.bat`. يطلب المشغل منع سكون النظام مؤقتًا طوال عمل خادم المحادثة (مع السماح بإطفاء الشاشة)، ويعيد الحالة الطبيعية عند إيقافه. اترك نافذة المشغل مفتوحة.
- لإيقاف خادم Open WebUI الذي بدأه هذا المشغل فقط وإعادة السماح بالسكون، استخدم `D:\LocalAI\Platform\STOP-CHAT.bat`؛ لن يوقف Ollama.
- يبقى الخادم على `http://127.0.0.1:8080` محليًا فقط.
- أنشئ أول حساب عند فتح الواجهة؛ أول حساب يصبح المسؤول.
- لا تفتح المنصة على الشبكة أو الإنترنت بهذه الإعدادات؛ الربط مقيد بـ localhost.

## اختبار النموذج

بعد التثبيت، شغّل `D:\LocalAI\Platform\VERIFY-MODEL.bat`.
هذا الاختبار يستخدم `think=false` و`num_ctx=4096` و`num_predict=128` ثم يفحص `message.content`؛ حتى لا يكرر الخطأ السابق الذي اعتبر حقل التفكير إجابة نهائية.
الاختبار يرسل سؤالًا واحدًا إلى النموذج المثبت ولا ينزل أي ملفات.

## استيراد الفلاتر

1. افتح المنصة وسجّل الدخول بحساب المسؤول.
2. أنشئ API key من Settings > Account > API Keys.
3. شغّل `D:\LocalAI\Platform\IMPORT-FILTERS.bat` والصق المفتاح في الإدخال المخفي.
4. يستورد الفلاتر الثلاثة، ويحدّث النسخ ذات المعرفات نفسها بعد حفظ نسخة احتياطية، ثم يتحقق من Active وGlobal.
5. احذف API key بعد انتهاء الاستيراد إن لم تعد تحتاجه.

الفلاتر تنفذ Python داخل خادمك. راجع ملفاتها قبل استيرادها. لا تمنح حساب المسؤول لأي شخص غير موثوق.

## ما الذي تفعله الفلاتر؟

- Trusted Content Guard: يعامل محتوى الملفات والويب وOCR والأدوات كبيانات غير موثوقة، وليس تعليمات تتحكم بالمساعد.
- Accuracy & Thinking: يضيف تعليمات الدقة ويطلب `think=true` فقط لنموذج Qwen المستهدف.
- Selective Self Review: يراجع العمليات والأكواد والردود التي تطلب المراجعة فقط. المراجع هو النموذج نفسه في استدعاء ثانٍ؛ هذا قد يلتقط بعض الأخطاء لكنه ليس تحققًا مستقلاً ولا يضمن الصحة. ضبطه على 4K و`think=false` لتقليل ضغط الذاكرة وتفادي الرد الفارغ.

## الصوت

- Speech-to-text: Whisper Small متعدد اللغات، CPU INT8 وVAD.
- FFmpeg مطلوب لمعالجة وتحويل التسجيلات في تثبيت pip. يحتفظ المثبت بمسار ffmpeg في `D:\LocalAI\Platform\ffmpeg-path.txt` ويضيفه لعملية Open WebUI عند التشغيل؛ لا يغيّر PATH العام للمستخدم.
- Text-to-speech: يترك محرك الخادم فارغًا؛ اختَر Web API أو Kokoro.js (Browser) من إعدادات المستخدم. التقرير الحالي أظهر أصوات Windows إنجليزية فقط؛ لا أفترض توفر صوت عربي. يمكنك إضافة صوت عربي من Windows Settings > Time & language > Speech إذا كان متاحًا لمنطقتك.
- مع 16GB RAM ومعالج CPU مدمج، لا تشغّل Whisper ونموذج Qwen الثقيل في وقت واحد عندما تكون الذاكرة ممتلئة. ابدأ بتسجيلات قصيرة.

## البحث على الإنترنت

يُفعّل DDGS المضمّن في Open WebUI بدون API key منفصل، مع تفعيل طلب التأكيد قبل البحث الخارجي. تأكد من Web Search في Admin Settings > Web Search، واجعل محرك البحث DuckDuckGo/DDGS والـ backend Auto. يجب أيضًا تشغيل Web Search capability للنموذج. البحث يرسل نص الاستعلام إلى مزود بحث خارجي؛ لا تضع كلمات مرور أو بيانات خاصة في الاستعلام.

## الأداء والجلسات الطويلة

تقرير الجهاز يوضح أن وضع السكون مضبوط على 180 ثانية (3 دقائق) سواء على الكهرباء أو البطارية. المثبت ومشغل الشات يمنعان سكون النظام مؤقتًا أثناء عملهما، دون منع إطفاء الشاشة ودون تغيير إعدادات Sleep الدائمة. لإيقاف منع السكون، أوقف Open WebUI باستخدام `STOP-CHAT.bat`.

المعالج رباعي الأنوية والـ GPU مدمج؛ Qwen 9B يعمل عبر CPU. الاستجابة ستكون أبطأ من الخدمات السحابية، والفلاتر لا تزيد عدد معاملات النموذج ولا تحوله إلى نموذج أكبر.

## ملفات السجلات

- تثبيت المنصة: `D:\LocalAI\Logs\platform-continuation-*.log`
- سجلات أوامر pip وFFmpeg وWhisper: ملفات stdout/stderr بجانب سجل التثبيت.
- تشغيل المنصة: `D:\LocalAI\Platform\Logs`
- حالة المحرك: `D:\LocalAI\ENGINE-STATUS.txt`
- حالة المنصة: `D:\LocalAI\Platform\PLATFORM-STATUS.txt`
- الحالة الكاملة: `D:\LocalAI\FULL-STATUS.txt`

## التراجع / الأمان

المثبت لا يحذف أي مجلد بيانات أو نموذج. إذا كانت `.venv` موجودة وغير صالحة، يحتفظ بها باسم `.venv-backup-...` قبل إنشاء بيئة جديدة. لا تحذف `D:\LocalAI\Models`.


## الإصدار 2.2 — إصلاح PowerShell 5.1

- إصلاح فحص وجود Open WebUI: لا يُستدعى `pip show` مباشرة من PowerShell، لأن PowerShell 5.1 قد يحوّل stderr الطبيعي (Package(s) not found أثناء التنصيب الجزئي) إلى NativeCommandError. الفحص يستخدم Python importlib.metadata داخل عملية معزولة، ويلتقط stdout/stderr كملفات.
- اكتشاف أي عملية تثبيت PowerShell أو pip تخص البيئة `D:\LocalAI\Platform\.venv`، وليس PID واحداً فقط.
- إذا لم تكن الحزمة مثبتة، يستأنف المثبّت من البيئة الحالية ويستخدم pip cache. لا يوقف عملية نشطة ولا يبدأ تثبيتاً موازياً.
- إصلاح علم إبقاء Windows مستيقظاً باستخدام قيمة UInt32 عشرية صحيحة.
- عرض مخرجات stdout/stderr مباشرة أثناء تثبيت pip.

شغّل `RUN-REPAIR.bat` من المجلد المستخرج (و`INSTALL-PLATFORM.bat` أصبح اسماً توافقياً يستدعي نفس المسار الآمن). إذا كانت عملية التثبيت السابقة لا تزال تعمل، انتظر المراقب حتى تنتهي.
