# LocalAI Studio Complete — الإصدار 2.4.0

حزمة منصة محلية لـ Windows تستخدم Ollama ونموذج Qwen المثبتين مسبقًا، مع Open WebUI وفلاتر تحسين الجودة، ودعم اختياري للصوت، والبحث، والتشخيص، والنسخ الاحتياطي.

## حماية تثبيت Ollama وQwen

حسب تقارير جهازك السابقة: Ollama 0.40.18 يعمل على 127.0.0.1:11434، والنموذج موجود بالاسم local-qwen35:latest / qwen3.5:9b-q4_K_M. هذه الحزمة:

- لا تثبّت Ollama ولا تعيد تشغيله.
- لا تسحب نموذج Qwen ولا تحذف أو تنقل D:\LocalAI\Models.
- تتحقق من وجود النموذج عبر /api/version و/api/tags قبل تثبيت المنصة.
- تعيد استخدام D:\LocalAI\Platform\.venv إذا كانت صالحة وPython فيها 3.11 أو 3.12.
- إذا كانت البيئة غير صالحة، تحفظها باسم .venv-backup-<timestamp> بدل حذفها.
- قد تنزّل Whisper Small كملف منفصل للصوت. هذا ليس نموذج Qwen، وغيابه لا يمنع الشات النصي.

## طريقة التشغيل

1. شغّل Ollama يدويًا وانتظر http://127.0.0.1:11434/api/version.
2. فك ضغط ZIP الإصدار 2.4.0 في مجلد جديد.
3. شغّل ONE-CLICK-SETUP.bat.
4. يفحص المشغّل كل ملفات الحزمة وبصمات SHA-256، ويتحقق من صياغة ملفات PowerShell، ثم يختبر مشغّل ExitCode بقيمتي 0 و37.
5. يراقب أي تثبيت سابق، ويستخدم قفل ملف حصريًا لمنع بدء تثبيتين متزامنين.
6. بعد انتهاء التثبيت شغّل D:\LocalAI\Platform\START-CHAT.bat.
7. افتح http://127.0.0.1:8080 وأنشئ حساب المسؤول الأول.
8. شغّل VERIFY-MODEL.bat لاختبار استجابة Qwen دون تنزيله.
9. استورد الفلاتر الثلاثة عبر IMPORT-FILTERS.bat بعد إنشاء Admin API Key.

## إصلاح PowerShell 5.1

الإصدارات السابقة اعتمدت على Process.ExitCode في مواضع من المثبت والاسترداد، وقد أظهر جهازك قيمة فارغة رغم ظهور مخرجات Python. في 2.4.0 تُشغّل أوامر النظام عبر RUN-NATIVE-WITH-EXITCODE.ps1 الذي يقرأ LASTEXITCODE في نفس سياق تنفيذ Python أو pip أو FFmpeg، ثم يكتب النتيجة إلى ملف مستقل.

## المكونات

- Open WebUI 0.13.5 مثبت بإصدار ثابت.
- Python 3.11 أو 3.12 وبيئة افتراضية مستقلة.
- 3 فلاتر: Trusted Content Guard، Accuracy & Thinking، Selective Self Review.
- faster-whisper وPyAV 14.0.1، مع Whisper Small متعدد اللغات CPU INT8 وVAD عند نجاح التنزيل.
- FFmpeg عبر WinGet إن توفر.
- DuckDuckGo/DDGS مع طلب تأكيد قبل إرسال الاستعلام إلى مزود البحث.
- الربط الافتراضي محلي فقط على 127.0.0.1:8080.

## أدوات الصيانة

- DIAGNOSTICS.bat: قراءة حالة Ollama وQwen والبيئة والحزم والواجهة وFFmpeg وWhisper والمساحة. ينشئ تقريرًا فقط.
- BACKUP-LOCALAI.bat: نسخة SQLite متسقة من قاعدة محادثات Open WebUI مع مفتاح التوقيع والفلاتر وملفات الحالة. لا تنسخ Qwen أو بيئة Python أو ذاكرة Whisper.
- CHECK-LOCALAI.bat: فحص سريع يستخدم LASTEXITCODE بدل Process.ExitCode.
- VERIFY-MODEL.bat: اختبار inference فعلي.
- STOP-CHAT.bat: يوقف عملية Open WebUI التي سجلها المشغل فقط، ولا يوقف Ollama.

النسخة الاحتياطية قد تحتوي سجل المحادثات ومفتاح توقيع Open WebUI. احتفظ بها في مكان خاص، ولا تشاركها علنًا. لا تتضمن مرفقات الملفات المرفوعة أو ذاكرة المتجهات.

## الخصوصية والأداء

- الربط محلي على 127.0.0.1 فقط. لا تغيّره إلى 0.0.0.0 ولا تفتح المنفذ على الإنترنت.
- أول حساب في Open WebUI يصبح المسؤول.
- راجع ملفات Python قبل استيراد الفلاتر؛ فهي تنفذ داخل خادم Open WebUI.
- أزل Admin API Key بعد استيراد الفلاتر إذا لم تعد تحتاجه.
- البحث الخارجي يرسل نص الاستعلام إلى مزود البحث بعد التأكيد؛ لا تضع أسرارًا أو بيانات شخصية في الاستعلام.
- Qwen 9B المحلي على CPU أبطأ من الخدمات السحابية. مع ذاكرة 16 GB تجنّب تشغيل Whisper والمراجعة الذاتية الثقيلة بالتزامن عند ضغط الذاكرة.
- المراجعة الذاتية استدعاء ثانٍ للنموذج نفسه؛ لا تمثل تحققًا مستقلًا ولا تضمن الصحة.

## السجلات والمسارات

- سجل التثبيت: D:\LocalAI\Logs\platform-continuation-*.log
- سجلات أوامر النظام: D:\LocalAI\Logs\*.stdout.log و*.stderr.log و*.exitcode.txt
- سجلات Open WebUI: D:\LocalAI\Platform\Logs
- حالة المنصة: D:\LocalAI\Platform\PLATFORM-STATUS.txt
- بيانات الواجهة: D:\LocalAI\Platform\Data
- النسخ الاحتياطية: D:\LocalAI\Backups

## حدود الاختبار

التحقق من الحزمة في Windows يستخدم محلل PowerShell 5.1 قبل التثبيت ويختبر رمزَي الخروج 0 و37. مع ذلك، لم يتم تنفيذ التثبيت الكامل على جهاز المستخدم من بيئة البناء هذه؛ نتيجة التشغيل على جهازك هي الاختبار النهائي.
