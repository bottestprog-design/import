# دليل استيراد فلاتر Local AI

1. افتح `http://127.0.0.1:8080` وسجل الدخول كمسؤول.
2. من Settings > Account أنشئ API Key.
3. شغّل `D:\LocalAI\Platform\IMPORT-FILTERS.bat`.
4. الصق المفتاح؛ لن يظهر أثناء الكتابة ولن يحفظه البرنامج في ملف.
5. عند النجاح سترى كل Filter باسم `[OK]`، وحالته Active وGlobal.
6. احذف المفتاح من الحساب بعد الاستيراد إذا لم تعد تحتاجه.

إذا فشل الاستيراد، افتح Admin Panel > Functions وتأكد أن كل عنصر من نوع Filter. لا تفعّل فلتر لم تراجع محتواه. الفلاتر تشغّل Python داخل الخادم بصلاحيات عملية Open WebUI.
