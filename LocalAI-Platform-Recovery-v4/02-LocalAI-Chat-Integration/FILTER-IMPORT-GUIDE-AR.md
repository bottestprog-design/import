# دليل استيراد الفلاتر — Open WebUI 0.13.4

> الفلاتر الثلاثة ملفات Python تنفّذ داخل منصة المحادثة. لا تستورد ملفات مجهولة، ولا تفتح Open WebUI على الإنترنت العام.

## الاستيراد التلقائي الموصى به (المسار الصحيح؛ لا تبدأ بالاستيراد اليدوي)
1. شغّل `D:\LocalAI\Platform\START-CHAT.bat` واترك نافذة التشغيل مفتوحة.
2. افتح `http://127.0.0.1:8080` وأنشئ حساب المسؤول الأول. لا تشارك الحساب أو مفتاح الجلسة.
3. افتح **Settings → Account** وأنشئ API Key للمسؤول. في التثبيت الجديد يتم تفعيل API Keys من مشغّل التشغيل. إذا لم يظهر الخيار في قاعدة بيانات قديمة، افتح **Admin Panel → Settings → Authentication** وفعّل API Keys ثم احفظ.
4. شغّل `D:\LocalAI\Platform\IMPORT-FILTERS.bat`.
5. الصق API Key في مطالبة الإدخال المخفية. المستورد يتصل بـ `127.0.0.1` فقط؛ لا يحفظ المفتاح ولا يكتبه في السجل.
6. المستورد ينشئ الفلاتر أو يحدّث النسخ التي تحمل نفس IDs، ويحفظ نسخة احتياطية من أي نسخة موجودة قبل تحديثها، ثم يفعّلها ويجعلها Global.
7. بعد نجاح الاستيراد احذف API Key من Settings → Account إذا لم تكن تحتاج API integrations أخرى؛ المفتاح يملك صلاحيات حساب المسؤول.
8. افتح محادثة جديدة مع `local-qwen35` لاختبار الفلاتر.

## الاستيراد اليدوي عند تعذر API Key
افتح **Admin Panel → Functions → Import**، واستورد ملفات `.py` الثلاثة من `D:\LocalAI\Platform\Filters` واحدًا بعد الآخر، ثم فعّلها واجعلها Global. لا تستورد وظائف من مصدر غير موثوق؛ الفلاتر تشغّل Python داخل خادمك.

## إعداد البحث على الإنترنت
1. مشغّل التشغيل يضبط DDGS على Auto ويفعّل البحث، ويطلب موافقتك قبل إرسال أي عبارة بحث إلى مزود خارجي.
2. افتح Admin Panel → Settings → Web Search، وتأكد من تفعيل Web Search، واختيار DDGS كمحرك وAuto كـ Backend، وتفعيل **Web Search Confirmation**. DDGS مضمّن مع تثبيت Open WebUI القياسي ولا يحتاج مفتاح API.
3. افتح Admin Panel → Models → Edit `local-qwen35`، وفعّل Built-in Tools / Web Search، واجعل Function Calling على Native.
4. فعّل زر Web Search في المحادثة عند رغبتك في بحث حالي. إذا لم يستدعِ النموذج الأداة، جرّب Legacy Function Calling كحل توافق؛ نماذج 9B قد لا تنفذ استدعاء الأدوات بنفس موثوقية النماذج الأكبر.
5. لا ترسل إلى البحث أي استعلام يتضمن كلمات مرور أو مفاتيح API أو معلومات حساسة.

## ترتيب الفلاتر
- `01-Trusted-Content-Guard.py` — priority 0: يضيف تعليمات للتعامل مع الملفات والصفحات ونتائج الأدوات كبيانات غير موثوقة.
- `02-Accuracy-Thinking.py` — priority 1: يضيف قواعد الجودة ويرسل `think: true` للنموذج `local-qwen35`؛ هذه قيمة Boolean المتوافقة مع Qwen 3.5.
- `03-Selective-Self-Review.py` — priority 20: يراجع انتقائيًا الطلبات الحسابية والبرمجية والطلبات التي تطلب التدقيق، ثم يحدث نص الرسالة ونص العرض معًا.

## اختبار آلي قبل الاستيراد
شغّل `D:\LocalAI\Platform\CHECK-LOCALAI.bat` للفحوصات الأساسية، أو نفّذ `D:\LocalAI\Platform\.venv\Scripts\python.exe D:\LocalAI\Platform\TEST-FILTERS.py --filters-dir D:\LocalAI\Platform\Filters` لاختبار منطق الفلاتر دون اتصالات خارجية.

## اختبار بعد الاستيراد
1. اكتب: `اكتب 17 × 19 وراجع الناتج.` المتوقع أن يعطي 323 مع شرح مختصر.
2. اكتب: `راجع هذا الكود واكتشف أخطاءه: ```python
print(1/0)
``` ` المتوقع أن يشرح سبب الخطأ ويقترح إصلاحًا.
3. افتح إعدادات النموذج أو سجل Ollama وتأكد أن طلب Qwen لا يرجع خطأ 400 متعلقًا بقيمة think.

## حدود المراجعة
المراجعة تستخدم النموذج نفسه في مرور ثانٍ؛ قد تكتشف أخطاء، لكنها ليست تحققًا مستقلًا ولا تضمن صحة الجواب. إذا أصبح الرد بطيئًا جدًا، افتح إعدادات Valves في `03-Selective-Self-Review` وأوقفه مؤقتًا أو ارفع حد المراجعة.

## الصوت
من **Settings → Audio** للمستخدم:
- Speech-to-Text Engine: اختر **Local Whisper** (أو اتركه على Local/Default). لا تختَر Web API إذا كنت تريد Whisper المحلي؛ Web API يستخدم التعرف المدمج في المتصفح بدل Whisper.
- Whisper Model: `small`، مع الإعدادات البيئية في مشغل الحزمة (`int8` وVAD).
- Language: اختر Arabic إذا كنت تتحدث بالعربية غالبًا، أو Auto إذا تتنقل بين اللغات.
- Text-to-Speech: اختر **Web API**؛ هذا يستخدم أصوات المتصفح/Windows. هذه الحزمة لا تثبّت نموذج TTS محليًا مستقلًا. إذا لم يظهر صوت عربي، أضف صوتًا عربيًا من Windows Settings → Time & language → Speech ثم أعد تشغيل المتصفح.

## الخصوصية
كل واجهة الخادم مربوطة بـ `127.0.0.1` فقط. التسجيلات التي ترفعها للمنصة قد تُحفظ في `D:\LocalAI\Platform\Data\cache\audio\transcriptions` وفق إعدادات Open WebUI؛ احذفها إذا لم تعد تحتاجها. البحث الخارجي يتطلب موافقة تظهر قبل كل استعلام، لكنه يرسل نص الاستعلام إلى مزود DDGS خارجي عند الموافقة.
