# LocalAI Platform Recovery v4 — إصلاح منصة المحادثة فقط

## ماذا أثبت تقرير جهازك؟
- Ollama 0.40.18 يعمل ويستجيب للـ API.
- النموذج `local-qwen35:latest` / `qwen3.5:9b-q4_K_M` موجود ومكتمل في `D:\LocalAI\Models`.
- `D:\LocalAI\Platform` غير موجود أصلاً؛ لذلك لا يوجد Open WebUI ولا بيئته الافتراضية ولا الفلاتر ولا اعتماديات الصوت.
- المثبت الكامل السابق توقف في مرحلة تنزيل Qwen قبل أن ينتقل إلى مرحلة تثبيت المحادثة. لذلك هذه الحزمة تتجاوز مرحلة المحرك ولا تعيد تنزيل Qwen.

## التشغيل
1. فك ضغط ZIP بالكامل إلى مجلد مستقل.
2. شغّل `RUN-REPAIR.bat` بزر مزدوج.
3. الأداة تتحقق من Ollama والنموذج الموجودين عبر API، ثم تثبت Open WebUI داخل `D:\LocalAI\Platform\.venv`، وتنسخ الفلاتر الأصلية وتختبرها، وتثبت أدوات الصوت.
4. بعد اكتمال التثبيت تحاول تشغيل Open WebUI في الخلفية، وتنتظر استجابة HTTP حقيقية من `/ready` لمدة تصل إلى 180 ثانية، ثم تفتح المتصفح على `http://127.0.0.1:8080`.

## ما الذي لا تفعله؟
- لا تثبت Ollama ولا توقف خدمته الحالية.
- لا تنفذ `ollama pull` ولا تنزل Qwen من جديد.
- لا تغير `OLLAMA_MODELS` ولا تنقل أو تحذف أي blobs أو manifests.
- لا تحذف قاعدة بيانات أو إعدادات أو ملفات من `D:\LocalAI`.
- إذا كان هناك مجلد Platform موجوداً من محاولة سابقة، تحافظ على البيانات وتعيد استخدام البيئة المتوافقة، وتنقل فقط بيئة Python غير المتوافقة إلى مجلد backup بدلاً من حذفها.

## لماذا Python 3.11؟
التقرير أكد وجود Python 3.11.9. توثيق Open WebUI الحالي ينص على أن Python 3.11 يعمل مع تثبيت pip، لذلك يستخدمه هذا المثبت بدلاً من تنزيل Python 3.12 بلا داعٍ. إذا وجد 3.12 يفضله، وإذا لم يجد 3.11/3.12 يثبت 3.12 من WinGet.

## الصوت
يثبت FFmpeg و`faster-whisper` و`av==14.0.1`، ويحاول تنزيل Whisper Base متعدد اللغات بصيغة CPU INT8 لتقليل ضغط الذاكرة على جهاز 16GB. إذا فشل تنزيل الصوت بسبب الشبكة، لا يحذف تثبيت المحادثة؛ راجع سجل التثبيت. يمكن إعادة تشغيل المثبت لمتابعة النواقص.

## الفلاتر
يتم نسخ الفلاتر الثلاثة الأصلية واختبارها برمجياً. تفعيلها داخل Open WebUI يحتاج حساب المسؤول الأول:
1. افتح صفحة المحادثة وأنشئ حساب المسؤول الأول.
2. من Settings > Account أنشئ API Key.
3. شغّل `D:\LocalAI\Platform\IMPORT-FILTERS.bat` وأدخل المفتاح في المطالبة المخفية. لا تحفظ الحزمة أو السكربت المفتاح.

## سجلات ونتيجة الإصلاح
- `D:\LocalAI\Logs\platform-recovery-*.log`
- `D:\LocalAI\Logs\platform-install-*.log`
- `D:\LocalAI\Platform\Data\open-webui-*.stdout.log`
- `D:\LocalAI\Platform\Data\open-webui-*.stderr.log`
- `D:\LocalAI\ENGINE-STATUS.txt`
- `D:\LocalAI\Platform\PLATFORM-STATUS.txt`
- `D:\LocalAI\FULL-STATUS.txt`

## اختبارات بعد التثبيت
- شغّل `D:\LocalAI\Platform\CHECK-LOCALAI.bat`.
- افتح `http://127.0.0.1:8080`.
- اختر `local-qwen35:latest` وتأكد من نجاح محادثة قصيرة بالعربية.
- بعد إضافة API Key فعّل الفلاتر عبر المستورد.

**مهم:** نجاح التثبيت لا يعني أن Qwen خضع لاختبار توليد جديد؛ لم يشغّل هذا الإصلاح اختبار inference حتى لا يحمل نموذج 9B في الذاكرة أثناء تنزيل Open WebUI/Whisper. حالة النموذج تحققت من Ollama API ووجود الوسم المحلي. اختبر أول رسالة بعد تشغيل المنصة.


## سلامة الحزمة
قبل أي تغيير، يفحص `RUN-REPAIR.bat` بصمات SHA-256 لجميع الملفات عبر `VERIFY-PACKAGE.ps1`. إذا فشل التحقق، لا يبدأ الإصلاح.
